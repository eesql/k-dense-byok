# macOS 首版保留本机代码执行

用户明确指定 Mac mini 或 Mac Studio 部署，首版不做执行环境隔离，取代此前建议的 Linux + Docker 路线。登录与租户归属校验用于约束网页和 API；Agent 仍以宿主机 OS 用户权限执行本地代码，因此文件目录、独立进程和模型网关均不能构成执行层面的跨租户安全边界。

同一 OS 用户的 shell 可能读取其他租户数据及平台凭据，平台网关的预算限制也不能约束绕过网关、直接使用取得的供应商凭据的调用。用户已确认首版面向全体使用者互相信任的内部协作场景，不适用于互不信任的客户。

初始容量设计参考为 20 人、5 个同时运行任务；Mac 的实际容量需要实测。后续需要承载互不信任租户时，应先引入执行隔离，再扩大使用范围。
