# 同时支持租户自带和平台供给模型访问

用户在多租户设计访谈中确认 Q3=C：支持租户自带 API Key／OAuth，以及平台提供模型访问。相较只支持其中一种，双模式既保留 BYOK 使用方式，也允许平台为没有自带凭据的租户提供访问。

每个项目明确选择供给方式；调用失败时由用户手动切换，不自动改用另一方的凭据或额度。首版平台供给接入 OpenRouter API，通过独立模型网关管理平台主 Key、租户访问令牌、模型预算与并发上限；BYOK 保留现有供应商 API Key／OAuth 支持。

平台管理员配置租户模型预算，达到预算后拒绝新调用；费用基于可获得的用量和价格估算，不承诺供应商账单硬上限。首版不做充值与支付，Modal 等外部服务由租户自带凭据。

用户确认项目仍有聊天、子代理、远程任务或后台工作运行时拒绝切换供给；暂停调度并确认空闲后重建工作进程，保留磁盘中的历史与科研记录。共享凭据更新后，空闲工作进程重载，忙碌进程完成当前工作后重载；重载前拒绝新的模型任务并显示待生效状态。
