# 以实验室或团队作为租户

用户确认租户是实验室或团队，一个租户拥有多个项目，成员在租户内协作。项目保留为科研工作空间，与租户归属分开建模，避免把现有项目目录误当作用户身份或执行隔离边界。

首版在内网通过管理员邀请使用；采用用户名密码与一次性邀请链接，平台管理员创建租户，租户负责人邀请或移除成员；每个用户归属一个租户。首版不接 SSO 或邮件发送。

同一租户的成员互相信任，共享项目、聊天和自带模型访问。跨租户的网页与 API 访问需要身份和归属校验；执行层面的信任边界见 [macOS 首版部署决定](0003-macos-trusted-host.md)。
